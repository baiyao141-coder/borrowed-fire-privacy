二、设备权限、本机存储与剪贴板

Android 测试包申请“访问网络”权限，用于您主动发起的联机连接。此权限无需系统弹窗授权；应用不申请相机、录音、通讯录、定位或共享存储的运行时权限。游戏通过系统 WebView 显示内容，使用 AndroidX WebKit 适配库；这些与广告、统计或社交登录 SDK 不同，本项目未为它们配置独立用户数据上传服务。

声音播放与声音诊断不需要麦克风，也不进行录音。读取屏幕尺寸、触控坐标、按键操作及动效偏好，仅用于适配画面和响应游戏输入。输入绑定保存的是游戏动作对应的按键或鼠标键代号，触控布局保存的是控件位置及尺寸倍率，不记录您在其他应用中的输入。

仅在您点击“复制邀请”“复制诊断”等按钮时，游戏将对应文本写入剪贴板。游戏不会在后台读取剪贴板；在邀请输入框中主动粘贴时，粘贴操作由系统提供。使用系统分享功能时，由您选择分享目标；收件人会收到您选择分享的邀请内容，请勿公开自己的临时席位凭证。

本机存储用于游戏档案、设置和连接恢复，不用于广告画像或跨应用追踪。游戏服务端未设置账号 Cookie，Android WebView 已关闭第三方 Cookie；网络托管平台可能使用其自身的安全机制，我们不将其表述为游戏完全不使用任何浏览器存储。

四、保存地点、期限和安全措施

本机数据保存在您正在使用的设备上，持续到您清除相应应用或站点数据。卸载 Android 应用或在系统设置中清除应用数据会删除本机游戏档案、设置、保存的服务器地址与相应会话数据。Android 测试包关闭了应用备份与设备迁移备份；请勿将本机档案当作云存档。

临时房间和对局保存在游戏服务器运行内存中。房主主动退出、服务器停止或重启时房间失效并从游戏业务内存移除。正常运行时，房间创建超过四小时、连续三十分钟无房间活动，或房主连接中断超过约九十秒，将由约每秒运行的清理任务关闭。短暂掉线的席位可能在恢复窗口内保留。清除会话存储可能使您失去恢复席位的能力。

请求限流记录在游戏服务进程内存中暂存网络连接来源与计数，用于防止过量请求；约每秒清理超过六十秒的旧计数条目。通过托管代理连接时，业务进程看到的来源地址也可能是代理地址。游戏业务没有将每次访问记录写入玩家档案或对局数据库。

服务器运行诊断日志可能记录启动状态、自检结果，以及少量异常连接的主机地址与来源地址。当前测试启动器将这些输出追加到服务器的临时运行日志文件；该文件未配置自动到期删除，停止服务也不等于文件立即删除。我们依据仍需排查的问题、安全事件或依法保存的需要确定保留范围，问题排查结束后人工删除不再需要的日志。托管方自身的网络与安全日志有其独立保留规则。

主动发送的反馈用于回复和解决您提出的问题。我们按问题处理、后续核实或处理相关争议实际必要的范围保存，并在不再需要时删除；您可以发送邮件要求查阅、更正或删除相关通信内容。因法律规定需要继续保存的，仅在相应必要范围内保存和保护，不另作其他用途。

当前政策主站的访问数据由 GitHub Pages 及相关服务基础设施处理。GitHub 会为安全目的记录并保存 Pages 访客 IP；本项目不建立网页访客数据库，也不通过政策正文读取本机游戏存储。GitHub 根据服务交付、安全、争议处理及适用法律需要确定其数据保留范围和期限；我们未取得可据以承诺固定删除天数的站点专属配置，不能直接修改或删除 GitHub 独立控制的全部基础设施日志。您可通过 GitHub 隐私声明列明的渠道请求说明或行使相应权利，也可先联系本政策列明的邮箱。

历史备用渠道的访问数据仅在访问旧 Sites 地址时涉及。其服务方按实际页面交付、安全、争议处理和法律要求确定保存期限；未确认该渠道已注销，不把迁移主站视为自动删除旧渠道日志。相关请求可通过 OpenAI 隐私请求门户或 Cloudflare 隐私政策列明的渠道提出，也可先联系我们。

保存地区取决于实际使用的服务。本机数据位于您的设备，局域网对局业务数据位于您选择的电脑房主；当前 GitHub Pages 政策主站与 GitHub Codespaces 联机服务由 GitHub 在美国及其服务实体或子处理者所在的其他地区处理必要数据，不作中国境内专属存储承诺。若您访问历史备用 Sites 地址，OpenAI 可能在美国及其关联方或服务提供商所在的其他地区处理必要访问数据，Cloudflare 主要在美国及欧洲经济区保存信息，并可能为全球服务在其他地区访问或处理信息。我们不会把 HTTPS、免费服务器或发布隐私说明等同于已完成个人信息跨境处理所需手续。面向公众提供新的联网服务前，将按实际服务部署、适用要求和处理活动补充必要告知并完成相应安排。

公网测试连接使用 HTTPS／WSS，并对可连接地址、请求来源和房间身份进行校验；局域网或电脑本机服务可能使用 HTTP／WS。本项目没有承诺对设备上的本地记录进行专门加密。我们采取与现阶段处理范围相适应的访问限制和安全措施，但无法保证任何网络或存储方式绝对安全。发现可能危害个人信息权益的安全事件时，将依法采取补救措施并履行相应告知义务。
